Column dictionary for normalized source tables

Inspected representative Parquet footers at revision 473b9ea659064ac13f63b11b9d6b77829ded6b6d on 16 October 2026. This dictionary covers all ten data/tables/ families plus frame-label and dense-index tables. Per-file Arrow schemas remain authoritative where optional fields vary. Nullability means permitted by the inspected schema, not measured non-null coverage. JSON payloads preserve source-defined nested fields; they are not replaced with invented enumerations or units.

Time-of-day fields are nanoseconds without capture date. Offset fields are recording-relative values in their own timestamp domain; do not assume different domains interchangeable. Exact joins require recording/camera/channel identity and compatible published timestamps. The frame-label split field is a legacy sampling-group label; its folders now use sample_group= and no benchmark split is asserted.

Nested calibration and GNSS fields

The inspected calibration fields_json contains intrinsic and extrinsic; obtain per-camera parameters and transforms there rather than substituting nominal lens specifications. GNSS fields_json contains the decoded pose fields; the flattened Viewer column dictionary in DATASET_SCHEMA.md lists exposed position, velocity, orientation, validity, and RTK fields. It is a projection, not the normalized GNSS source schema.

Producer-confirmed seven-camera extrinsics

Every existing camera row in data/tables/calibrations/ adds the non-null calibrated_extrinsics struct. Original columns and source JSON remain unchanged. This includes explicit camera identity, signed yaw/tilt, rig and front-reference camera centres in millimetres, and row-major homogeneous transforms with named direction. The tilted front camera is +4 degrees downward. The rig axes are X left, Y forward, Z up; the front reference subtracts [0,0,1546] mm and is not an optical frame. See the complete schema, equations, provenance and join rules. Existing source schema_version values are retained; the additive model is identified by its own calibration_id.

Devkit camera timing and partial recordings

For every recording, the devkit defaults to camera payload rec_timestamp (rec_time_offset_ns) for camera selection, synchronization and exported times, and main gnss payload timestamp (time_offset_ns) for GNSS. Untimed quality-flagged GNSS messages define excluded gaps; leading portions can be trimmed from an export without rejecting the whole recording. Raw table fields and annotation source identities are unchanged. See exact fields and trimming policy.
